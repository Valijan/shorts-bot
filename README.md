# 🎬 Shorts Bot — нарезка видео в YouTube Shorts через Telegram

Присылаешь боту видео или ссылку, а он:
1. распознаёт речь (Whisper; русский, узбекский, английский и др.);
2. находит лучшие моменты: с ключом Claude API отбирает ИИ по смыслу, без ключа работает алгоритм по звуку, речи и смене сцен;
3. переводит в вертикаль 9:16, решая отдельно для каждой сцены: камера плавно следит за лицом (живым или аниме) или за движением, а если двое по краям или это общий план — кадр целиком на размытом фоне;
4. добавляет крупные субтитры с подсветкой слов (оригинал или перевод RU/UZ/EN) и заголовок;
5. присылает готовые клипы.

## Что понадобится (всё можно сделать с телефона)

| Что | Где взять |
|---|---|
| Токен бота | @BotFather → `/newbot` |
| API ID и API Hash | https://my.telegram.org → API development tools |
| VPS-сервер | Ubuntu 22.04/24.04, **4 ядра, 8 ГБ RAM**, 40+ ГБ диск |
| (необяз.) Ключ Claude | https://console.anthropic.com |
| Приложение для сервера | **Termius** (iOS/Android) — подключение по SSH |

## Установка (5 команд)

Подключись к серверу через Termius и выполни:

```bash
# 1. Docker
curl -fsSL https://get.docker.com | sh

# 2. Код бота (загрузи папку shorts-bot на сервер или склонируй репозиторий)
cd shorts-bot

# 3. Настройки
cp .env.example .env && nano .env      # вставь токен, API ID/Hash; сохранить: Ctrl+O, Enter, Ctrl+X

# 4. Один раз отвязать бота от облачного API Telegram (нужно для файлов до 2 ГБ)
curl "https://api.telegram.org/bot$(grep BOT_TOKEN .env | cut -d= -f2)/logOut"

# 5. Запуск
docker compose up -d --build
```

Логи: `docker compose logs -f bot` · Перезапуск: `docker compose restart bot` · Обновление: `docker compose up -d --build`

Первый запуск занимает несколько минут: скачивается модель Whisper.

## 🚀 Запуск на RunPod (GPU — быстро, оплата только за время работы)

1. RunPod → **Pods → Deploy**: GPU **RTX 4090 / RTX A5000** (Community Cloud), шаблон **RunPod PyTorch** (CUDA 12), **Volume Disk 30 ГБ**.
2. Открой **Connect → Web Terminal** и вставь:
   ```bash
   cd /workspace && git clone https://github.com/Valijan/shorts-bot && cd shorts-bot && bash runpod.sh
   ```
3. Ответь на вопросы (токен бота и т.д.) — бот запустится.
4. Закончил работу — **Stop** pod (платишь только за диск, копейки). Следующий запуск:
   ```bash
   cd /workspace/shorts-bot && git pull && bash runpod.sh
   ```

На RunPod бот работает через обычный API Telegram: файлы **до 20 МБ**, большие видео присылай **ссылкой**.
Распознавание на GPU (`large-v3`): ~3–5 минут на час видео.

## Пользование

- `/start` — приветствие
- `/settings` — сколько клипов, длина, язык субтитров, режим кадра
- `/id` — узнать свой ID (впиши его в `ALLOWED_USERS`, чтобы ботом пользовался только ты)
- Пришли **видеофайл** (до 2 ГБ) или **ссылку**

## Скорость

Медленнее всего распознаётся речь. На 4-ядерном сервере с `WHISPER_MODEL=small`
1 час видео обрабатывается примерно 20–40 минут. Ускорить можно так:
- `WHISPER_MODEL=base` — в 2–3 раза быстрее, но немного хуже точность;
- сервер с GPU и `WHISPER_DEVICE=cuda` — быстрее в 10+ раз.

## YouTube-ссылки

С серверов YouTube иногда требует подтверждение «я не робот». Решение такое: выгрузи cookies
из браузера (расширение «Get cookies.txt LOCALLY»), положи файл в `data/cookies.txt`
и добавь в `.env` строку `YTDLP_COOKIES=/data/cookies.txt`.
