# 🎬 Shorts Bot — нарезка видео в YouTube Shorts через Telegram

Присылаешь боту видео или ссылку, а он:
1. распознаёт речь (Whisper; русский, узбекский, английский и др.);
2. находит лучшие моменты: с ключом Claude API отбирает ИИ по смыслу, без ключа работает алгоритм по звуку, речи и смене сцен;
3. переводит в вертикаль 9:16, решая отдельно для каждой сцены: камера плавно следит за лицом (живым или аниме) или за движением, а если двое по краям или это общий план — кадр целиком на размытом фоне;
4. добавляет крупные субтитры с подсветкой слов (оригинал или перевод RU/UZ/EN) и заголовок;
5. присылает готовые клипы.

## Режимы видео (/settings → «Что за видео»)

| Режим | Что ищет | Кадр 9:16 |
|---|---|---|
| 🎬 Обычное | лучшие моменты по смыслу речи | лицо / движение / размытый фон |
| 🎥 Фильм | кульминации, культовые фразы, экшен (речь + движение + громкость), без титров | как обычно |
| ⚔️ MLBB | килы (Savage, Maniac, Triple/Double Kill, Wiped Out, Лорд), советы стримера, смешные моменты | 🎮 сверху весь кадр, снизу крупно герой |
| 🔫 PUBG M | килы, хэдшоты, клатчи, Chicken Dinner, советы, смешные моменты | 🎮 сверху весь кадр, снизу крупно прицел |
| 🚗 GTA 6 | баги, фейлы и WASTED, погони, взрывы, перестрелки, пасхалки, реакция стримера | 🎮 камера стримера сверху, геймплей снизу |

Режим можно указать прямо в сообщении со ссылкой: `mlbb 2 https://youtu.be/…` (2 клипа MLBB), `фильм 5 <ссылка>`, `pubg <ссылка>`.

### Длинные эфиры и Twitch

- Ссылка на запись Twitch (`twitch.tv/videos/…`) работает как обычная. Бот дополнительно смотрит чат записи:
  секунды, где зрители «взорвались», получают больший вес при выборе моментов (для любого игрового режима).
- Из длинного эфира можно разобрать только окно: `gta 10 2:00:00-4:00:00 <ссылка>` скачает и разберёт
  третий и четвёртый час, а в подписи клипа будет время из оригинала. Кусок длиннее 5 минут считается окном,
  короче — готовым клипом.
- Видео длиннее 1,5 часа качается в 720p. Эфир длиннее 6 часов целиком не берётся — нужно окно
  (лимит меняется переменной `MAX_HOURS` в `.env`).
- В игровых режимах на видео длиннее 20 минут речь распознаётся только в самых ярких местах
  (по звуку, движению и чату) — около 30% эфира, поэтому разбор идёт в разы быстрее. Если бот выбрал
  клип вне этих мест, речь в нём дораспознаётся перед монтажом. Вернуть полное распознавание:
  /settings → ✂️ Нарезка → «Весь эфир». Минус быстрого режима: тихий разговорный момент без реакции
  чата бот может пропустить.
- Звук любого длинного видео распознаётся кусками по 15 минут и не грузится в память целиком.
- Чат читается через неофициальный запрос веб-плеера Twitch. Если Twitch его поменяет, бот продолжит
  работать по звуку, движению и речи, просто без этого сигнала.
С ключом Claude ИИ выбирает моменты по расшифровке и сигналам (громкость, вспышки, события), без ключа работает алгоритм по тем же сигналам.

| 👀 Сначала выбор | /settings → ✂️ Нарезка → «Сначала выбор»: бот шлёт кадры найденных моментов, отмечаешь нужные, монтирует только их |

| 📋 Текст | к каждому клипу — название, описание и хэштеги для публикации |
| 🛑 Очередь | `/queue`, `/cancel` |
| ⏸ Автостоп | сервер RunPod выключается сам после 15/30/60 мин без дела (`/stop` — сразу) |

## Установка (5 команд)

Подключись к серверу через Termius и выполни:

```bash
# 1. Docker
curl -fsSL https://get.docker.com | sh

# 2. Код бота (загрузи папку shorts-bot на сервер или склонируй репозиторий)
cd shorts-bot

# 3. Настройки
cp .env.example .env && nano .env      # вставь токен, API ID/Hash; сохранить: Ctrl+O, Enter, Ctrl+X

# 4. Один раз отвязать бота от облачного API Telegram (нужно для файлов до 2 ГБ)
curl "https://api.telegram.org/bot$(grep BOT_TOKEN .env | cut -d= -f2)/logOut"

# 5. Запуск
docker compose up -d --build
```

Логи: `docker compose logs -f bot` · Перезапуск: `docker compose restart bot` · Обновление: `docker compose up -d --build`

Первый запуск занимает несколько минут: скачивается модель Whisper.

## 🚀 Запуск на RunPod (GPU — быстро, оплата только за время работы)

1. RunPod → **Pods → Deploy**: GPU **RTX 4090 / RTX A5000** (Community Cloud), шаблон **RunPod PyTorch** (CUDA 12), **Volume Disk 30 ГБ**.
2. Открой **Connect → Web Terminal** и вставь:
   ```bash
   cd /workspace && git clone https://github.com/Valijan/shorts-bot && cd shorts-bot && bash runpod.sh
   ```
3. Ответь на вопросы (токен бота и т.д.) — бот запустится.
4. Закончил работу — **Stop** pod (платишь только за диск, копейки). Следующий запуск:
   ```bash
   cd /workspace/shorts-bot && git pull && bash runpod.sh
   ```

На RunPod бот работает через обычный API Telegram: файлы **до 20 МБ**, большие видео присылай **ссылкой**.
Распознавание на GPU (`large-v3`): ~3–5 минут на час видео.

## Пользование

- `/start` — приветствие
- `/settings` — сколько клипов, длина, язык субтитров, режим кадра
- `/id` — узнать свой ID (впиши его в `ALLOWED_USERS`, чтобы ботом пользовался только ты)
- Пришли **видеофайл** (до 2 ГБ) или **ссылку**

## Скорость

Медленнее всего распознаётся речь. На 4-ядерном сервере с `WHISPER_MODEL=small`
1 час видео обрабатывается примерно 20–40 минут. Ускорить можно так:
- `WHISPER_MODEL=base` — в 2–3 раза быстрее, но немного хуже точность;
- сервер с GPU и `WHISPER_DEVICE=cuda` — быстрее в 10+ раз.

## YouTube-ссылки

С серверов YouTube иногда требует подтверждение «я не робот». Решение такое: выгрузи cookies
из браузера (расширение «Get cookies.txt LOCALLY»), положи файл в `data/cookies.txt`
и добавь в `.env` строку `YTDLP_COOKIES=/data/cookies.txt`.
